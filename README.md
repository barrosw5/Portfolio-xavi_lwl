# Personal Portfolio - xavi_lwl

A professional front-end developer portfolio designed to showcase projects, technical skills, and creative direction through a modern, interactive web interface.

## Description

This project serves as a central hub for my professional identity. It is built using a clean-code approach with vanilla JavaScript and the GSAP (GreenSock Animation Platform) library to ensure smooth, high-performance visual transitions. The architecture focuses on a responsive "mobile-first" strategy, ensuring a premium experience across all devices.

The core focus of this repository is:
- Advanced UI/UX: Implementation of sophisticated entry animations and scroll-based reveals using GSAP.
- Responsive Engineering: A fully adaptive layout using CSS Flexbox and Media Queries.
- Modern Aesthetics: Utilization of custom typography, glassmorphism effects, and a curated color palette.
- Analytics Integration: Optimized with Vercel Analytics for tracking user engagement and performance.

## Features

- Immersive Hero Section: Dynamic title animations that engage users immediately upon page load.
- Interactive Navigation: A responsive menu system designed for intuitive exploration.
- Smooth Motion Design: Carefully timed staggered animations for content reveal, preventing visual clutter.
- Project Showcase: A dedicated section for highlighting key repositories and live demonstrations.
- Performance Optimized: Minimalist code structure for fast loading times and SEO efficiency.

## Technologies Used

- HTML5: Semantic structure and content organization.
- CSS3: Custom styling, layout management, and visual effects.
- JavaScript (ES6+): Core interaction logic and DOM orchestration.
- GSAP (GreenSock): Advanced animation engine for smooth, complex visual transitions.
- Vercel: Hosting and real-time performance analytics.

## How to Use

1. Clone the repository: `git clone https://github.com/barrosw5/portfolio-xavi_lwl.git`
2. Open `index.html` in a web browser to view the local version.
3. To customize, modify the `css/style.css` for visual themes or `js/animations.js` to adjust GSAP timing and easing functions.
4. For deployment, this project is pre-configured for seamless integration with Vercel or GitHub Pages.

## Project Structure

- `index.html`: The main entry point and single-page application structure.
- `css/style.css`: Comprehensive global styles and responsive breakpoints.
- `js/animations.js`: Dedicated logic for GSAP timelines and interactive animations.
- `js/main.js`: Core JavaScript initialization.
- `libs/`: Local storage for essential third-party libraries (e.g., gsap.min.js).
